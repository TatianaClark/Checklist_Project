## Communication Best Practices

### ✅ Good Communication Examples

1. **Specific Request:**
   ```
   "Edit power_bi_checklist.html at C:\Users\Tatia\OneDrive\Checklists Hub\
   Add 'Machine Learning Basics' as new Core Concepts item"
   ```

2. **Priority Clear:**
   ```
   "High priority: Update index.html landing page title 
   from 'Interactive Checklists Hub' to 'Tatia's Checklists Hub'"
   ```

3. **Context Provided:**
   ```
   "Create new checklist for web development covering HTML, CSS, JavaScript.
   Use power_bi_checklist.html as template.
   Save to: C:\Users\Tatia\OneDrive\Checklists Hub\web_dev_checklist.html"
   ```

### ❌ Vague Communication Examples

- "Update the file" (which file?)
- "Make it better" (how?)
- "Add more content" (what kind?)

### 📝 Template to Use

```
Task: [What you want done]
File: [Full path to file]
Specific Request: [Exactly what to change]
Context: [Why you need this]
Priority: [High/Medium/Low]
```
