## 📊 How to Use the Checklists

### Basic Workflow
1. **Open HTML file** in any modern web browser
2. **Check items** as you learn or prepare
3. **Watch progress update** in real-time
4. **View widgets** on left (categories) and right (progress)
5. **Generate Report** (button on right) to see unchecked items
6. **Print report** or save as PDF for reference

### Key Features Explained

**Section Headers**
- Click to collapse/expand sections
- Shows % completion per section
- Turns green when 100% complete ✅

**Left Widget (Categories)**
- Shows all topics/sections
- Real-time percentage for each
- Green when complete
- Compact and balanced design

**Right Widget (Progress)**
- Overall completion percentage
- Items completed / total items
- Report button below
- Always visible while scrolling

**Reports**
- Click "📊 Report" button
- See all unchecked items organized by section
- Identify weak areas
- Print-friendly format
- Great for focused studying

**Data Persistence**
- Progress auto-saves to browser storage
- Close and reopen - your progress is there!
- No account needed
- Local storage only (on your device)
