# 📝 How to Rename a File in GitHub

## 🎯 Step-by-Step Guide

### Method 1: Using GitHub Web Interface (Easiest) ✅

#### **Rename `power_bi_checklist.html` to `index.html`:**

1. **Go to your GitHub repository**
   - Navigate to: `https://github.com/TatianaClark/PBI_Student_Checklist`

2. **Find the file you want to rename**
   - Look for `power_bi_checklist.html` in the file list
   - Click on the filename to open it

3. **Click the Edit/Rename Button**
   - Look for a **pencil icon ✏️** in the top right area of the file
   - Click it to enter edit mode

4. **Change the Filename**
   - At the very top of the editor, you'll see the filename in a text field
   - Change from: `power_bi_checklist.html`
   - Change to: `index.html`
   - The filename field is right next to the folder path

5. **Commit the Change**
   - Scroll down to the bottom
   - You'll see a section that says **"Commit changes"**
   - Add a message like: `Rename power_bi_checklist.html to index.html`
   - Click the green **"Commit changes"** button

6. **Done! ✅**
   - GitHub will rename the file
   - Wait 1-2 minutes for GitHub Pages to rebuild
   - Visit your site: `https://tatianaclark.github.io/PBI_Student_Checklist/`

---

### Method 2: Upload New File + Delete Old One (Alternative)

If the rename doesn't work, try this:

1. **Upload `index.html` as a new file**
   - Go to your repo
   - Click **"Add file"** → **"Upload files"**
   - Upload the `index_github.html` file from your computer
   - Rename it to `index.html` during upload
   - Commit

2. **Delete the old `power_bi_checklist.html`** (optional)
   - Click on `power_bi_checklist.html`
   - Click the **trash/delete icon 🗑️**
   - Confirm deletion

## 🔧 Troubleshooting

**Q: I can't find the pencil icon**
- A: Make sure you clicked on the filename itself to open the file view
- Look in the top right corner of the file content area

**Q: The filename field is grayed out**
- A: Try using Method 2 instead (upload new + delete old)

**Q: Changes aren't showing**
- A: Wait 2-3 minutes and do a hard refresh (Ctrl+Shift+R on Windows)
